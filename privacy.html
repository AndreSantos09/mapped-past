Privacy Policy — Mapped Past Pipeline

Last updated: 24 October 2026

Mapped Past Pipeline ("the tool") is a private, single-user software tool operated by André Oliveira Santos ("I", "me") to publish videos to my own YouTube channel, Mapped Past. It is not distributed to, installed by, or accessible to any other person.

1. What the tool does

  • Uploads videos that I produce to my own YouTube channel and sets their title, description, tags, category, language, thumbnail, privacy status and scheduled publish time.
  • Reads performance data (views, watch time, audience retention) of my own channel through the YouTube Analytics API, so that I can review how my videos perform.

2. Google user data the tool accesses

The tool uses the YouTube Data API v3 and the YouTube Analytics API through Google OAuth 2.0, with these scopes: youtube.upload, youtube and yt-analytics.readonly. The only Google account that authorizes the tool is my own channel account. The tool accesses:

  • Metadata of my own channel and videos (titles, descriptions, IDs, privacy status).
  • Analytics reports of my own channel.
  • An OAuth access token and refresh token for my own account.

The tool does not access data of any other YouTube user or channel, and it does not read, collect or store personal data of viewers.

3. How data is stored and protected

  • All data, including OAuth tokens, is stored only on my own computer, in files readable only by my user account.
  • No data is sent to any server that I operate, and no data is sold, shared, transferred or disclosed to any third party.
  • Data is kept only as long as I operate the channel. Tokens can be revoked at any time (see section 5).

4. Limited Use disclosure

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool also complies with the YouTube API Services Developer Policies and the YouTube Terms of Service, and is subject to the Google Privacy Policy.

5. Revoking access

Access granted to the tool can be revoked at any time from the Google account security settings at https://myaccount.google.com/permissions. Revoking access deletes the tool's ability to use the stored tokens.

6. Contact

Questions about this policy: mappedpast@gmail.com.
